# Как добавлять контент — ZAGA GAME

## Фото клуба

Папка: `assets/club/`

Форматы: `.jpg` `.jpeg` `.png` `.webp` (любой регистр).

- Главное фото Hero: назови файл **`hero.jpg`** (или `.png` / `.webp`)
- Остальные фото — любые имена → секция Atmosphere

После добавления: закоммить файлы. GitHub Action обновит манифест сам  
(или локально: `npm run assets` и закоммить `js/generated/club-images.js`).

## Обложки игр

Папка: `assets/games/`

**Вариант А (проще):** замени файл **с тем же именем** — больше ничего не нужно.

**Вариант Б:** новый файл с другим именем → открой `js/games.js` и поменяй одну строку:

```js
image: "assets/games/новое-имя.png"
```

**Вариант В:** `image: ""` — сайт ищет файл по названию игры сам (beat saber, gorn…).

После смены файлов нужен свежий манифест: Action на GitHub или `npm run assets`.

## Отзывы

`js/reviews.js` — массив `ZAGA_REVIEWS`. Пустой = секция скрыта.
